# Omniverse Pixar Hydra Engine [omni.hydra.pxr]

`omni.hydra.pxr` allows using the Pixar Hydra delegates in the Kit viewport.

It requires Vulkan enabled in the `kit-next` app. To enable Pixar render
delegates, start omni.app.next.kit with:
`--/renderer/enabled='rtx,pxr' --vulkan`

Hydra is a framework that enables the communication between multiple scene
graphs and multiple renderers.
